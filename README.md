# CT／CTA／MRI／MRA 臨床影像檢查決策導航

互動式繁體中文臨床影像選擇與教學工具。輸入病人症狀、檢查目的、急迫性、腎功能與安全條件，產生首選影像、替代方案、顯影劑判斷與安全提醒；並附示範病例、分級測驗與複習心智圖。

**網頁：** https://yht5582-source.github.io/Imaging-Navigator-/
**目前版本：** v1.8（2026-11-11）

> 僅供臨床教學與初步決策輔助，不取代主治醫師與放射科判斷。請勿輸入可辨識病人身分的資料。

## 決策引擎

規則式引擎，涵蓋：急性中風／大血管阻塞、顱內出血、SAH、TIA、小梗塞／後顱窩缺血、未破裂動脈瘤、頸動脈狹窄、腎動脈狹窄、主動脈剝離、肺栓塞、腦腫瘤、頭痛，以及「其他」（不自動推薦，提示洽影像科）。

主要規則：

- **症狀帶入目的**：選主要症狀會自動帶入對應的臨床疑問；未選目的時依症狀暫定並提示確認。
- **急症警示**：局部神經缺損、突發眩暈／共濟失調、雷擊樣頭痛、撕裂樣胸背痛、休克、低血氧、意識改變。
- **急性度判斷**：只在急診或發作 24 小時內，才因神經症狀改走中風路徑；超過 24 小時改為確認梗塞與次級預防。
- **時間敏感急症**（中風、出血、SAH、主動脈剝離、PE）不因腎功能或顯影劑疑慮而改選較慢的檢查。
- **情境調整**：
  - 已知動脈瘤合併急性頭痛 → 排除破裂
  - 症狀性頸動脈且為術前評估 → CTA／MRA，並提醒 2 週內血管重建
  - 腎動脈狹窄且 eGFR <30 或 AKI → Duplex US／MRA
  - 疑 PE 且含碘顯影劑嚴重反應 → V/Q scan
  - 穩定門診疑 PE → 先 Wells／PERC 與 D-dimer，需要時才 CTPA
  - 中風發作 6–24 小時 → 加做 CT perfusion 或 MRI DWI／PWI（DEFUSE-3／DAWN）
  - 腦出血且未滿 70 歲 → 提醒加做 CTA 排除血管病因
  - 懷孕疑 PE → 下肢超音波，再選 V/Q 或 CTPA
  - MRI 安全性未明 → 改以 CT／CTA 或超音波
- **安全提醒**：eGFR <30、AKI、透析、含碘或 Gadolinium 過敏、懷孕、幽閉恐懼、Metformin（eGFR <30 或 AKI 時）；輸入檢核（eGFR 範圍、未滿 18 歲、性別與懷孕不一致）。
- 第一次分析後，修改任何輸入會自動更新建議。

## 互動考題（40 題）

- **難度**：基礎 12 題、臨床應用 8 題、進階 8 題、高階 12 題。
- **選項順序**：每次載入隨機排列。
- **計分**：計分後顯示逐題詳解，並標示正確選項（綠）與錯選選項（紅）。
- **高階題涵蓋**：後循環中風的 CT／DWI 偽陰性、6–24 小時延長時間窗、ICH 血管病因與 spot sign、ACR–NKF CA-AKI 共識、GBCA 分類與 NSF、懷孕 PE、頸動脈 CEA 時機、含碘顯影劑嚴重反應的再檢查策略、不穩定主動脈剝離的 TEE。

## 複習心智圖

**14 大主題、226 個重點、24 個考點**，第一層預設收合：

1. 影像工具的本質與選擇邏輯（CT 早期缺血徵象、ASPECTS、CTP、MRI 序列、MRA 技術、輻射劑量）
2. 急症辨識與分流
3. 急性缺血性中風（IVT、EVT 時間窗與條件、stroke mimics）
4. 後循環中風與 TIA（HINTS、影像陷阱、ABCD²）
5. 顱內出血與 SAH（CTA 適應症、spot sign、Ottawa SAH rule、6 小時 CT 原則）
6. 未破裂顱內動脈瘤（影像選擇、破裂風險、追蹤與篩檢）
7. 頸動脈與頭頸血管（Duplex 閾值、症狀性狹窄、動脈剝離）
8. 胸部急症：主動脈剝離與肺栓塞（ADD-RS、Wells、PERC、年齡校正 D-dimer、YEARS、懷孕）
9. 腎動脈與腎血管性高血壓（ACR 2026、Duplex 指標、FMD）
10. 頭痛、腦占位與其他神經情境（SNOOP4、依病因選影像、LP 前 CT）
11. 含碘顯影劑安全（CA-AKI 閾值、Metformin、過敏樣反應、預處置）
12. MRI 與 Gadolinium 安全（Group I／II、NSF、腦部沉積、MR-conditional）
13. 特殊族群（懷孕胎兒劑量、兒童、CKD／透析）
14. 申請、判讀與影像後行動

複習工具：

- **關鍵字搜尋**：例如 ASPECTS、懷孕、Metformin。
- **只看考點**：只顯示 24 個考點主題。
- **遮蔽複習**：重點先模糊，點一下顯示答案。
- **全部展開／收合**。
- **列印心智圖**：只印心智圖與數字表。
- **必背數字速查**：22 項時間窗、閾值與用藥劑量。

## 技術說明

- 單一 `index.html`，純靜態網頁，無外部套件、無後端、無資料庫；所有輸入只在瀏覽器中運算，不儲存、不上傳。
- 心智圖內容集中在程式碼的 `/*MIND-START*/ … /*MIND-END*/` 區段（`MIND`、`MINDNUM` 陣列），修改內容不需動版面。
- 病例在 `cases` 陣列，考題在 `quizBank` 陣列（`[題目, 選項, 正解索引, 詳解, 難度]`）。
- 推送到 `main` 即由 GitHub Actions（`.github/workflows/pages.yml`）自動部署到 GitHub Pages。若網站無法開啟，請至 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**。

本機預覽：

```bash
python3 -m http.server 8000
```

然後開啟 http://localhost:8000 。

## 臨床依據與限制

- [ACR Appropriateness Criteria](https://acsearch.acr.org/)
- [ACR Renovascular Hypertension（2026）](https://acsearch.acr.org/docs/69374/Narrative/)
- [ACR Manual on Contrast Media](https://www.acr.org/Clinical-Resources/Clinical-Tools-and-Reference/Contrast-Manual)
- 另參考 AHA／ASA 急性中風與腦出血指引、ACR–NKF 顯影劑與腎功能共識、ESC 肺栓塞指引等。

限制：

- 規則為教學用途的簡化，並非逐一情境的完整適當性評分。
- 心智圖、考題與病例解析中的數值依常用指引整理，未逐條與原文核對，教學使用前請依最新版指引及院內政策確認。
- 急性中風、主動脈剝離等急症不可因腎功能不佳而延誤必要 CTA。
