# CT／CTA／MRI／MRA 臨床影像檢查決策導航

互動式繁體中文臨床影像選擇工具：輸入病人症狀、檢查目的、急迫性、eGFR、AKI、透析狀態、顯影劑過敏、MRI 禁忌與懷孕，產生首選影像、替代方案與安全提醒。

**網頁：** https://yht5582-source.github.io/Imaging-Navigator-/

## 功能
- 評估急性中風、腦出血、TIA、動脈瘤、頸／腎動脈狹窄、主動脈剝離、肺栓塞、頭痛和腦腫瘤。
- 提供 CT、CTA、MRI、MRA 及適當時的超音波／VQ scan 建議。
- 6 個示範病例、複製個別化報告、列印／另存 PDF。
- 純靜態單頁網頁，沒有後端或病人資料庫。

## 啟用 GitHub Pages
如網站仍無法開啟，進入 **Settings → Pages**，在 **Build and deployment → Source** 選擇 **GitHub Actions**，並檢查 **Actions → Deploy GitHub Pages** 的執行結果。

## 安全性
僅供教學和初步決策輔助，不取代醫師與放射科判斷。急性中風和主動脈剝離等急症不可因腎功能不佳而延遲必要 CTA。請勿輸入可辨識病人身分的資料。

參考：[ACR Appropriateness Criteria](https://acsearch.acr.org/) · [ACR Manual on Contrast Media](https://www.acr.org/Clinical-Resources/Clinical-Tools-and-Reference/Contrast-Manual)
